# Veil licensing history

## Current license

Beginning with the repository change that first adds the root `LICENSE` file
and this notice on 14 July 2026, the original Veil material is offered by
NaveLIL under **GNU AGPL v3.0 or later** (`AGPL-3.0-or-later`). The complete
terms are in [LICENSE](LICENSE).

## Language and translations

The root [LICENSE](LICENSE) contains the unmodified English AGPL text. GNU
states that only the original English license text specifies the legal
distribution terms; translations are explanatory and unofficial. The stable
SPDX identifier `AGPL-3.0-or-later` is used in package metadata independently
of documentation language.

Project documentation and the website may be written in Russian, English, or
both. A translated summary must never replace or modify the root license. For
readability, GNU maintains a list of
[unofficial license translations](https://www.gnu.org/licenses/translations.html),
including a linked Russian AGPL translation.

Contributions intentionally submitted for inclusion after this cutover are
accepted under the same license unless a file is clearly identified as
third-party material under different compatible terms.

## Earlier revisions

Some earlier package metadata and documentation described Veil as MIT-licensed,
although the repository did not contain a root license text. This change does
not revoke permissions that a recipient already received for an earlier
revision under the notices accompanying that revision. The license of a
historical checkout must therefore be determined from that checkout rather
than from the current branch.

There were no tagged stable releases at the AGPL cutover. Current preview
artifacts identify their exact source revision and include a corresponding
source archive so that their terms are unambiguous.

See [AUTHORS.md](AUTHORS.md) for the repository identity mapping and
[TRADEMARKS.md](TRADEMARKS.md) for the separate rules governing the Veil name
and Phase Shift logo.
