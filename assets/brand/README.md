# Veil brand assets

`phase-shift-mark.svg` is the canonical vector source for the Veil Phase
Shift mark used by the website and applications. Keep derivatives visually
consistent with this source and preserve a clear margin around the mark.

The asset is part of the Veil source distribution under
`AGPL-3.0-or-later`, but use of the name and mark as source identifiers is
also governed by [TRADEMARKS.md](../../TRADEMARKS.md). Modified builds should
use a distinct name and visual identity unless NaveLIL grants permission.
